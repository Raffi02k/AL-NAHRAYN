# ALNAHRAYN Fisk

Frontendprojektet ligger nu helt i `frontend/` och körs som en ren Vite SPA.

## Struktur

```text
frontend/
  index.html
  public/
  src/
    App.tsx
    main.tsx
    components/
    content/
    pages/
    styles/
  vite.config.ts
```

## Krav

- Node.js `>=22.13.0`

## Kommandon

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run test`
- `npm run lint`
